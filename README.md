# JavaScript Fundamentals, DOM, Modules & OOP

Repository ini berisi kumpulan latihan, eksperimen, dan catatan belajar **JavaScript**—mulai dari sintaks dan konsep dasar hingga manipulasi DOM, JavaScript Modules, Object-Oriented Programming (OOP), dan penggunaan Standard Library.

## Struktur Folder

- **`JS_Dasar/`** — Materi fondasi JavaScript: variabel, tipe data, operator, percabangan, perulangan, fungsi, array, dan objek.
- **`JS_Dom/`** — Latihan manipulasi Document Object Model (DOM): seleksi elemen, modifikasi konten dan atribut, serta *event handling*.
- **`JS_Modules/`** — Praktik modularisasi kode JavaScript menggunakan `export` dan `import`.
- **`JS_OOP/`** — Penerapan konsep Object-Oriented Programming di JavaScript: *constructor function*, *prototype*, `class`, *inheritance*, dan *encapsulation*.
- **`JS_Standar-Library/`** — Eksplorasi objek dan fitur bawaan (*built-in standard library*) pada JavaScript seperti `Array`, `String`, `Math`, `Date`, `JSON`, `Map`, dan `Set`.

## Ringkasan Topik

| Modul | Materi Utama |
| :--- | :--- |
| **JS Dasar** | Sintaks dasar, tipe data, struktur kontrol, fungsi, array, dan objek |
| **JS DOM** | Seleksi & manipulasi elemen HTML serta interaksi berbasis *event* |
| **JS Modules** | Pemisahan dan penggunaan ulang kode antarfile dengan ES Modules |
| **JS OOP** | Pemrograman berorientasi objek dengan *prototype* dan sintaks `class` |
| **JS Standard Library** | Pemanfaatan fitur dan objek bawaan JavaScript |

## Cara Menjalankan

1. *Clone* repository ini atau buka folder proyek di **Visual Studio Code**.
2. Untuk file latihan berbasis HTML/DOM maupun **JS Modules**, jalankan menggunakan ekstensi **Live Server** (atau server lokal) agar fitur `import`/`export` berjalan tanpa kendala CORS.
3. Untuk skrip JavaScript murni, kamu juga bisa menjalankannya lewat *Console* di *Developer Tools* browser atau menggunakan **Node.js** di terminal.
