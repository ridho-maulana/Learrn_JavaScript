Tipe Data
 -DOM memiliki representasi Data
 -Tidak terlalu banyak tipe data terdapat di DOM
 -Oleh karena itu,sebenarnya DOM sangat sederhana
  ,namun penggunaannya sangat bermanfaat

Tipe Data
 -Document
    Merupakan representasi dari halaman web
 -Node
    Merupakan base class untuk semua tipe data
    di DOM,seperti Document,Element,dan Attr
 -Element
    Merupakan representasi object element di halaman
    web,misal head,body,input,dan lain-lain
 -NodeList
    Merupakan array/collection yang berisikan Node
 -Attr
    Atau attribute,merupakan representasi object
    attribute dalam element
 -NamedNodeMap
    Merupakan collection yang berisikan Attr dalam
    bentuk Map
